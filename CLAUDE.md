# hireminds-pilot-app — правила для агентов

- Постановка задачи — описание issue в трекере и файлы в `docs/`; сообщение PM дополняет постановку.
- Перед PR: `npm run check` и `npm test` должны проходить. Новое поведение покрывается тестом в `test/`.
- Одна задача — одна ветка — один PR в `main`. PR описывает, что изменилось и как проверено.
- Логика — в `src/todos.ts` чистыми функциями; I/O только в `src/server.ts`.
- Зависимости не добавляются без указания в постановке.
- Секреты в репозиторий не попадают.
