# hireminds-pilot-app

Пилотное приложение для платформы Hireminds: список дел по HTTP. На нём роли-агенты выполняют задачи
от постановки до PR; репозиторий намеренно небольшой.

## Как запустить локально

Нужен Node.js версии 20 или новее (`engines.node` в `package.json`: `>=20`).

После клонирования репозитория:

```
npm ci                       # установить зависимости
npm run build && npm start   # собрать и запустить сервер: http://127.0.0.1:3000
npm test                     # запустить тесты (vitest)
npm run check                # проверить типы
```

Отдельного dev-сервера с автоперезапуском в `package.json` нет: сервер запускается из сборки (`dist/server.js`).

## API

| Метод и путь | Что делает |
| --- | --- |
| `GET /todos?filter=all\|open\|done&limit=<N>` | Список дел; `filter` и `limit` необязательны |
| `GET /todos/stats` | Сводка по делам: `total`, `open`, `done` |
| `POST /todos` `{ "title": "..." }` | Добавить дело |
| `POST /todos/:id/complete` | Отметить выполненным |

### Ограничение количества дел

Параметр `limit` задаёт максимальное число дел в ответе `GET /todos`:

- принимает положительное целое число от 1 до `9007199254740991`; начальные нули допустимы (`limit=01` — то же, что `limit=1`);
- сначала применяется `filter`, затем из результата берутся первые `limit` дел в порядке добавления;
- без параметра `limit` возвращается весь список, как раньше;
- если подходящих дел меньше, чем `limit`, возвращаются все доступные;
- ограничение действует только на ответ: список дел, статистика и следующий идентификатор не меняются;
- это не постраничная навигация: параметра пропуска нет, получить следующую порцию нельзя;
- недопустимое значение (пустое значение, `limit=0`, `limit=-1`, `limit=1.5`, `limit=abc` и подобные) даёт HTTP 400.

Примеры для списка дел A, B, C, D, созданных в таком порядке, где A и C выполнены:

```
$ curl -s 'http://127.0.0.1:3000/todos?filter=open&limit=1'
[{"id":2,"title":"B","done":false}]

$ curl -s 'http://127.0.0.1:3000/todos?filter=open&limit=2'
[{"id":2,"title":"B","done":false},{"id":4,"title":"D","done":false}]

$ curl -s -i 'http://127.0.0.1:3000/todos?limit=0'
HTTP/1.1 400 Bad Request
Content-Type: application/json; charset=utf-8

{"error":"limit must be a positive safe integer"}
```

Сводка `GET /todos/stats` считается по всему списку, query-параметры (в том числе `filter` и `limit`)
игнорируются, запрос ничего не меняет. Пример ответа для списка из трёх дел, одно из которых выполнено:

```
$ curl -s http://127.0.0.1:3000/todos/stats
{"total":3,"open":2,"done":1}
```

Состояние хранится в памяти процесса и теряется при перезапуске.

## Структура

- `src/todos.ts` — чистые функции списка дел.
- `src/server.ts` — HTTP-обработчик и запуск сервера.
- `test/` — тесты vitest.
- `docs/` — постановки и документы задач (см. `docs/README.md`).
