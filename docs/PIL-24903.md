## Цель и сценарии

Потребитель API получает количество всех, открытых и выполненных дел текущего списка одним запросом. Разработчик может получить ту же статистику через экспортируемую чистую функцию `todoStats(list: TodoList)`.

1. Для пустого списка функция и `GET /todos/stats` возвращают `{ "total": 0, "open": 0, "done": 0 }`.
2. После создания трёх дел и завершения одного статистика равна `{ "total": 3, "open": 2, "done": 1 }`.
3. После завершения всех трёх дел статистика равна `{ "total": 3, "open": 0, "done": 3 }`.
4. Повторное чтение статистики не меняет список или результат последующих чтений при отсутствии операций записи.

## Контракт и критерии приёмки

- `src/todos.ts` экспортирует `todoStats(list: TodoList)`, возвращающую объект ровно с тремя числовыми полями `{ total, open, done }`, без дополнительных полей и оболочки.
- `total` — число элементов `list.items`; `done` — число элементов с `done === true`; `open` — число элементов с `done === false`. Для корректного `TodoList` значения целые, неотрицательные, `total === open + done`.
- Функция не меняет `list`, `nextId`, массив `items`, порядок элементов или поля объектов дел. I/O отсутствует.
- `GET /todos/stats` возвращает HTTP 200 и JSON указанного формата с существующим заголовком `application/json; charset=utf-8`. Подсчитывается текущее состояние в памяти процесса.
- Статистика охватывает весь список: параметр `filter` не меняет результат. Обработка query-параметров соответствует существующей маршрутизации по pathname.
- Создание дела увеличивает `total` и `open` на один; завершение открытого дела увеличивает `done` и уменьшает `open` на один при прежнем `total`. Повторное завершение уже выполненного дела не меняет статистику.
- Существующие маршруты и ответы сохраняются. Другие HTTP-методы для `/todos/stats` получают существующий ответ 404 `{ "error": "not found" }`.
- В `test/todos.test.ts` покрыты пустой список, смесь открытых и выполненных, все выполненные и отсутствие мутаций входа. README описывает новый метод, путь и формат ответа.

Используются существующие `TodoList`, `Todo.done`, состояние HTTP-сервера, Node.js >=20, TypeScript и Vitest из проекта. Внешние сервисы не требуются. Начало реализации зависит от утверждения этой редакции спецификации через платформу.
