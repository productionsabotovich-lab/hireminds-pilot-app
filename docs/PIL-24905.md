## Контракт

`todoStats(list: TodoList)` — чистая синхронная функция в `src/todos.ts`, возвращающая объект ровно с полями `{ total: number, open: number, done: number }`:

- `total` равно `list.items.length`;
- `done` равно числу элементов с `done === true`;
- `open` равно числу элементов с `done === false`;
- для корректного `TodoList` выполняется `total === open + done`;
- вызов не изменяет `list`, `nextId`, массив `items`, его порядок и поля элементов.

`GET /todos/stats` возвращает HTTP 200 и JSON с результатом `todoStats` для всего текущего состояния сервера. Content-Type соответствует существующему JSON API. Параметры запроса, включая `filter`, не меняют статистику. Чтение статистики не меняет состояние.

## Пользовательские сценарии и критерии приёмки

1. До добавления дел функция и HTTP-маршрут возвращают ровно `{ "total": 0, "open": 0, "done": 0 }`.
2. Для трёх дел, из которых одно выполнено, результат равен ровно `{ "total": 3, "open": 2, "done": 1 }`.
3. Для двух выполненных дел результат равен ровно `{ "total": 2, "open": 0, "done": 2 }`.
4. После добавления открытого дела `total` и `open` увеличиваются на один; после завершения дела `open` уменьшается на один, `done` увеличивается на один, `total` не меняется. Повторное завершение уже выполненного дела не меняет счётчики.
5. После вызова функции исходный объект, значения `nextId`, массив и элементы совпадают с состоянием до вызова; замороженный корректный вход также обрабатывается без ошибки.
6. Ответ содержит только `total`, `open`, `done`, без массива дел, обёртки и дополнительных метаданных.
7. Существующие маршруты сохраняют поведение; README содержит `GET /todos/stats` и назначение трёх счётчиков.

## Исключения и зависимости

Вход функции соответствует существующему типу `TodoList`; валидация некорректных объектов JavaScript не входит в объём. Для других HTTP-методов и неизвестных путей сохраняется текущий ответ 404. Маршрут статистики не принимает тело и не создаёт новых правил ошибок. Счётчики относятся только к памяти текущего процесса и после перезапуска обнуляются вместе со списком.

Зависимости: существующие типы `TodoList`/`Todo`, состояние сервера, Node.js >=20, TypeScript и Vitest из текущего проекта. Внешние сервисы и новые пакеты не нужны.
